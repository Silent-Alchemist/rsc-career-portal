The **RSC Intelligence Portal** (The RSC MyCareer Project) is a high-fidelity analytical dashboard designed for the Rocket Soccar Confederation. It serves as a central hub for advanced scouting, multi-player performance tracking, and historical contract data for thousands of Rocket League competitive players.

## 💙💛 The Purpose
In a league as vast as the RSC, raw data can be overwhelming. The MyCareer Project translates complex spreadsheets into an immersive, high-contrast visual interface built on core principles of speed, data integrity, and analytical depth.

With the launch of **v.2026.6.23: Scouting Simulator Update**, the portal has evolved beyond personal career lookups. It provides scouts and General Managers with a live regression-based workspace to track real-time contract value, simulate potential roster metrics, and index active team hierarchies instantaneously.

## 💎 Core Features
* **Weighted Career Averages:** A custom mathematical engine that calculates player performance across multiple seasons, weighting stats by Games Played (GP) to ensure historical integrity.
* **The OVR System:** A dynamic 0-99 rating system based on tier-specific benchmarks, recognizing elite statistical dominance.
* **Live OLS Scouting Telemetry:** Runs live browser-memory Ordinary Least Squares (OLS) linear regressions per competitive tier to calculate true statistical expectations based on MMR, generating immediate Value Buy or Roster Deficit contract flags.
* **Multi-Property Active Search:** Deep-indexes player records alongside active organizational data, letting scouts view entire rosters by typing the name of an individual, team, or franchise.
* **Hypothetical Stat Simulator:** A high-precision simulation engine tracking 0.05 increments that models projected statlines against active tier standards to predict true player rating ceilings.
* **Identity Verification (⊕):** A robust tracking system that uses RSC IDs to link player aliases and name changes across the league's history.

## 🛠️ Technical Stack
* **Frontend:** React 18 + Vite + React Router
* **Styling:** Tailwind CSS + CSS Custom Properties (Theme-Reactive Tier Systems)
* **Data Processing:** Linear Regression Baselines & Custom weighted-average logic
* **Export:** High-Fidelity HTML-to-Image 4K PNG snapshot generation for draft-board reports
